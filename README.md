# 训练打卡日志

一个可以直接发布在 GitHub Pages 上的纯静态网页:每月导入一份 xlsx 训练与饮食计划表,然后每天打开网页打卡。

零构建、零后端:HTML + CSS + 原生 ES Modules,表格解析用 [SheetJS](https://sheetjs.com/)(CDN 按需加载),数据存在浏览器 localStorage。

## 功能

- **导入月计划**:选择 xlsx 文件即解析,可导入多个月份随时切换
- **模版下载**:没有现成的表?页面可下载自动生成的模版 xlsx(结构与解析约定一致),按月填写后导入
- **今日打卡**:当天运动、三餐、练后补给一览,逐项盖章打卡;休息日运动项自动豁免
- **体测记录**:体重 / 腰围输入,称重日自动高亮提醒
- **月历总览**:每格显示完成度圆点,全天完成盖「完」字朱红印章
- **完整计划表 / 执行规则 / 食材替换 / 每周采购**:xlsx 里的参考内容全部呈现
- **数据统计**:连续全勤天数、月完成率、体重腰围曲线
- **备份**:一键导出全部数据为 JSON,换设备后导入恢复

## 本地预览

```bash
python3 serve.py
# 打开 http://localhost:8000
```

`serve.py` 等价于 `python3 -m http.server 8000`,只是额外禁用了浏览器缓存 —— ES Modules 分多文件加载,缓存可能把新旧模块混拼导致页面失灵,禁缓存后改代码刷新即生效。

## 发布到 GitHub Pages

1. 在 GitHub 网页端新建一个仓库(比如叫 `train`),**不要**勾选初始化 README
2. 推送本地代码:

   ```bash
   git remote add origin https://github.com/<你的用户名>/train.git
   git push -u origin main
   ```

3. 仓库页面 → **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → Branch 选 **main** / 目录 **/(root)** → Save
4. 等 1 分钟左右,访问 `https://<你的用户名>.github.io/train/`

## xlsx 计划表格式约定

直接用你正在用的月度计划表改即可,也可以点页面上的「下载模版」拿一份自动生成的模版(含全部 5 个 sheet 与示例内容)在其上修改。本仓库 `.gitignore` 已忽略 `*.xlsx`,个人身体数据不会被提交。一个标准文件包含以下 sheet:

### 1. 计划表(必需,sheet 名含「计划表」)

| 日期 | 星期 | 运动(时间) | 早餐 | 午餐 | 晚餐 18:00 | 练后 21:00 |
|------|------|------------|------|------|------------|------------|
| 9/14 | 一 | 游泳40min (19:30~20:20) | 燕麦40g+… | … | … | … |

- 第一行为标题(如 `2026年9月减脂计划表(9/14~9/30) 女 30岁 163cm 59kg`),年份从这里推断
- 表头含「日期」即可被识别;运动 / 早餐 / 午餐 / 晚餐 / 练后 按表头关键词匹配,列顺序可调
- 日期支持 `9/14`、`2026/9/14`、`9月14日` 或 Excel 日期格式
- 运动列写「休息 / 完全休息」即视为休息日;括号内时间会被单独提取展示
- 表头里带时间(如 `晚餐 18:00`)会显示为该餐的提示时间

### 2. 执行规则(可选,sheet 名含「规则」)

一行一条,自动编号展示。规则里写 `称重:9/14、9/21、9/28…` 会被提取为称重提醒日。

### 3. 食材替换参考(可选,sheet 名含「替换」或「食材」)

单列行为分组标题,两列行为「类别 | 说明」键值对。

### 4. 每周采购表(可选,sheet 名含「采购」)

同上格式,按周分组。

### 5. 每日执行记录(可选,sheet 名含「记录」或「打卡」)

**表头定义了打卡项**,可以自定义:

| 日期 | 星期 | 计划运动 | 运动完成✓ | 三餐按计划✓ | 无零食甜饮✓ | 饮水≥2L✓ | 23:00前睡✓ | 体重(kg) | 腰围(cm) | 备注 |
|------|------|---------|-----------|------------|------------|----------|-----------|---------|---------|------|

- 表头含 `✓` 的列 → 变成打卡勾选项
- 含「体重 / 腰围」→ 变成数值记录项
- 含「备注」→ 出现备注输入框
- 缺这个 sheet 时用默认 5 项(运动 / 三餐 / 无零食 / 饮水 / 早睡)

## 数据与隐私

- 所有数据(计划 + 打卡)只存在**当前浏览器**的 localStorage,不上传任何服务器
- 清除浏览器数据会丢失记录,请定期用页面上「备份 → 导出全部数据 (JSON)」保存副本
- 换电脑 / 换浏览器:导出 JSON → 在新设备「备份 → 从 JSON 恢复」
- 计划表文件本身(`*.xlsx`)已被 `.gitignore` 排除,不会进入 Git 仓库

## 技术栈

- 原生 ES Modules,无构建步骤;`.nojekyll` 关闭 GitHub Pages 的 Jekyll 处理
- SheetJS `xlsx@0.18.5` 从 jsDelivr CDN 按需动态加载(仅点导入时)
- 设计:明亮 Editorial 风,系统衬线字体栈,零字体加载成本
